# Projects

A curated directory of 51 active projects maintained by [Escoffier Labs](https://github.com/escoffier-labs), [Lidless Labs](https://github.com/lidless-labs), and [Solomon Neas](https://github.com/solomonneas).

The directory lives at [solomonneas.github.io/projects](https://solomonneas.github.io/projects/).

## Local preview

```sh
npm run serve
```

Open `http://localhost:4173`.

Run the test suite with:

```sh
npm test
```

## Curation

`projects.js` is the source of truth. The list is maintained by hand so recent commit activity does not decide what appears. Profile, asset, policy, shared-theme, support, and duplicate adapter repositories stay out of the directory.

The site has no runtime dependencies, analytics, cookies, or external API calls.
